# PASIGNAE-Web_Portal_TheBinary101
PASIGNAE – Diocese of Pasig Church Web Portal

PASIGNAE is a centralized web portal designed to support and connect the Diocese of Pasig’s churches through a unified digital platform. The system streamlines communication, improves information accessibility, and enhances administrative efficiency across parishes within Pasig City.

This web portal allows users to easily access church announcements, schedules, events, and important updates, while also providing church administrators with tools to manage content, coordinate activities, and maintain organized records. PASIGNAE aims to modernize how the diocese engages with its community by offering a reliable and user-friendly online presence.

Key Features:

Centralized information hub for all Diocese of Pasig churches
Event scheduling and announcements management
User-friendly interface for both visitors and administrators
Organized content management for church-related updates
Accessible platform for community engagement

Purpose:
This project was developed as a capstone initiative to address the need for a more efficient and accessible digital system for church coordination and communication within the Diocese of Pasig.
